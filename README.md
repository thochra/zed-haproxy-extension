# HAProxy Syntax for Zed

This is a [Zed](https://zed.dev) extension for HAProxy configuration files.

## Usage

To use this extension, files must end with the `haproxy.cfg` or `haproxy.conf` extension eg. `test.haproxy.cfg` or `haproxy.cfg`.

## Build and install in Zed

You can install this as a dev extension directly in Zed:

1. Open Zed's command palette (`Cmd+Shift+P`)
1. Run `zed: install dev extension`
1. Navigate to and select the `zed-haproxy-extension` directory

Zed will automatically build and load the extension from the source directory.
